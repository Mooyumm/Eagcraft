# EagleReplica 灵感库

一个使用 SwiftUI/AppKit 编写的原生 macOS 素材管理器。界面与工作流参考 Eagle，但所有代码、数据结构和实现均为独立开发。

## 当前能力

- 响应式三栏界面：`980pt` 窗口自动收起检查器，宽窗口恢复完整三栏。
- 图片导入与拖放：复制原文件、生成缩略图、记录像素尺寸/格式/文件大小。
- 本地持久化：素材与索引保存在 `~/Library/Application Support/EagleReplica/Library`。
- 文件夹：新建、重命名、删除、拖入指定文件夹、素材移动分类。
- 导航与布局：文件夹浏览前进/后退、侧栏和详情栏独立展开/收起，并记住上次打开的栏目、文件夹、标签或智能文件夹。
- 智能文件夹：支持全部/任一条件，以及名称、格式、标签、文件夹、颜色、日期、来源、注释、尺寸、大小、形状和评分规则。
- 素材元数据：标题、注释、来源网址、标签、色标、五星评分。
- 状态化详情栏：文件夹、标签、智能文件夹、单张和多张素材分别显示对应信息；支持移回未分类、恢复、移到回收站及带确认的永久删除。
- 批量整理：`Command` 离散多选、`Shift` 连续范围选择，统一修改注释、标签、文件夹、评分或移入回收站。
- 库内拖放：把单个素材或当前多选集合直接拖到左侧文件夹完成分类。
- 重复项扫描：支持 SHA-256 完全重复检测与感知哈希视觉相似检测，可按全部、当前列表或已选素材扫描。
- 搜索、筛选、排序、回收站、按打开时间排列的最近使用、稳定随机模式。
- 标签管理：标签统计、进入标签素材、重命名和删除标签。
- 双击预览、缩放、前后切换、Finder 定位、打开来源网页。
- 浏览器拖图收集器：参考 Eagle 的 `480×276pt` 浅色横向双栏，左侧投放进入未分类，右侧可直接投放到指定文件夹。

## 在 Xcode 中运行主程序（推荐）

1. 在 Xcode 中打开 `Xcode/InspirationLibrary/InspirationLibrary.xcodeproj`。
2. Scheme 选择 `InspirationLibrary`，运行目标选择 `My Mac`。
3. 给主 App 和 Extension 两个 Target 选择同一个开发团队，然后按 `⌘R`。

这个工程会生成标准的 `灵感库.app`，拥有 Dock 图标、正常键盘焦点，并内嵌 Safari 扩展。不要再把根目录 `Package.swift` 当成日常运行入口；它主要用于命令行构建和自动化测试。

### 常用快捷键

- `⇧⌘N`：新建文件夹并立即进入重命名。
- `⌘I`：导入图片。
- `Space`：预览当前所选素材；正在编辑文字时不会抢占输入。
- `⌥⌘S`：显示或隐藏左侧栏。
- `⌥⌘I`：显示或隐藏右侧详情栏。

也可以在终端运行：

```bash
swift run EagleReplica
```

## Safari 扩展

1. 运行上面的 `InspirationLibrary` Scheme；Safari 扩展已经内嵌在同一个工程。
2. Safari → 设置 → 扩展，启用“灵感库网页采集器”，允许访问网页。
3. 保持“灵感库”在后台运行，从 Safari 拖动图片。

### 采集器触发逻辑

1. 扩展监听网页的 `dragstart`，但只有拖动目标是 `<img>`、懒加载图片、`srcset/currentSrc`、目标内的图片，或目标及其祖先的 CSS `background-image` 时才继续。
2. 每次拖图生成唯一 `sessionID`；扩展把图片地址、来源页、标题、建议文件名、像素尺寸、Safari 真实拖拽起点和会话发送到新版独立桥 `127.0.0.1:49158`。
3. 扩展同时使用浏览器登录态预取原始图片并按会话发送给 App，用于 Pinterest、登录站点和防盗链图片的下载兜底。单张上限 80 MB，缓存最多 4 项/160 MB，120 秒自动过期。
4. 主程序收到 `imageDragStarted` 后，按 Safari 提供的真实屏幕坐标把左侧投放区放到当前拖拽点，并在屏幕边缘自动修正；拖文字、普通链接或页面空白不会触发。
5. 图片投放到左侧虚线区域会进入未分类，投放到右侧某个文件夹行会直接分类入库，同时保留来源页面和标题。
6. 松开后采集框不会立即消失，而会依次显示“正在加入素材库 → 已成功入库”；失败时保留错误原因和“重试/关闭”，不会静默失败。
7. 原图复制、格式识别、缩略图和索引保存全部成功后才算入库；失败会清理半成品。同一次拖拽会话只允许成功入库一次。
8. 成功后主 App 自动进入目标文件夹或未分类、选中新素材并显示成功提示；采集框确认成功后再收起。
9. 点击底部“建立或选择文件夹”会唤醒主程序、新建文件夹并立即进入内联重命名。

本机桥接支持 Safari 的 CORS `OPTIONS` 预检、TCP 分片、JSON 元数据和按会话传输的原始图片二进制；只监听本机回环地址。正式版独占 `49158`，避免仍在运行的旧 EagleReplica（使用 `49157`）截走采集任务；如果新端口被占用，主窗口底部会显示非模态状态条并自动重试。

这里刻意不使用“Safari 发生任意拖动就弹窗”的全局兜底，因为系统级拖动事件无法可靠区分图片、文字和链接。要获得精确触发，需要启用浏览器扩展并保持“灵感库”在后台运行。

Chromium 浏览器也可以在扩展管理页开启开发者模式，直接“加载已解压的扩展程序”并选择 `BrowserExtension/`。

## 验证

```bash
swift build
swift test
```

浏览器桥只监听本机回环地址，不对局域网或公网开放。

## 目录

- `Sources/EagleReplica/`：当前主程序源码。
- `Tests/EagleReplicaTests/`：导入、缩略图、元数据、文件夹、智能规则、批量编辑、重复扫描和持久化测试。
- `BrowserExtension/`：Safari/Chromium 共用的 WebExtension 源码。
- `Xcode/EagleReplicaCollector/`：由 Xcode 生成并已验证可构建的 Safari 扩展工程。
- `Xcode/InspirationLibrary/`：正式 macOS App 与 Safari Extension 工程，直接引用当前主源码。
